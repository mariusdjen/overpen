# Security Policy

## Supported versions

Only the latest version of Overpen, on the Mac App Store and on the `main` branch, receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately instead: on this repository, open the **Security** tab and click **Report a vulnerability**. Describe the problem, the steps to reproduce it and the macOS version you use.

You will get an answer within 7 days. Once the problem is confirmed, a fix is published as soon as possible and you are credited in the release notes if you wish.

## What Overpen can and cannot do

- The app runs in the macOS sandbox.
- It has no network access and sends nothing anywhere.
- It asks for no special permission (no Accessibility, no Screen Recording).
- Drawings are never saved. Settings are stored on the Mac only.

# Politique de sécurité

Seule la dernière version d'Overpen (Mac App Store et branche `main`) reçoit les correctifs de sécurité.

Pour signaler une faille, n'ouvrez pas d'issue publique : utilisez l'onglet **Security** de ce dépôt, puis **Report a vulnerability**. Une réponse est donnée sous 7 jours.
